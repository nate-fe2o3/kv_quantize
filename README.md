# kv-quantize

FibQuant: universal vector quantization for random-access KV-cache compression
of Qwen3.5 full-attention layers (radial-angular codebook, arXiv:2605.11478).
Persistent KV memory drops ~8x at b=2 bits/coord (k=4, N=256), ~5.2x at b=3
(pair-packed), ~3.9x at b=4.

- **Domain model and seams:** [`CONTEXT.md`](CONTEXT.md) — read this first.
- **Codebook construction:** [`scripts/build_codebook.py`](scripts/build_codebook.py)
- **Run-time codec:** `fibquant/codec.py` (prepared device state) and
  `fibquant/quantize.py` (packing + compatibility functions)
- **Transformers integration:** `fibquant/cache.py` (`FibQuantCache`, `enable_fibquant`)
- **Evaluations:** `scripts/eval_cuda.py` (Databricks/CUDA, see `env.yaml`) —
  a thin config over `fibquant/eval_harness.py`, tuned via the constants at
  the top of the script (no CLI arguments)
- **LongBench v2 (non-thinking):** `scripts/eval_longbench.py` — official
  THUDM protocol (0-shot prompt, chat template with thinking off, middle
  truncation at the 262k context window, regex-scored), paired baseline +
  FibQuant configs over the same cached prompts; constants: `LIMIT`,
  `BITS`/`SPEC_PATHS`, `OUTPUT_DIR`
- **Env sync:** `env.yaml` (Databricks custom env) is generated by
  `scripts/sync_env.py` from `pyproject.toml` + `uv export` of the lockfile;
  the `.githooks/pre-commit` hook regenerates it on `pyproject.toml` changes
- **Sanity checks:** `scripts/sanity.py` (roundtrip, logits, memory)
- **Long-range recall probe:** `scripts/key_recall.py`
- **Unit tests:** `pytest` (CPU-only; no model or GPU needed)

Quick start:

Every script is configured by constants at the top of its file (no CLI
arguments) and runs on Databricks — as a notebook or directly on the cluster
(`python scripts/<name>.py`), with the model/checkpoint volumes hardcoded:

```bash
uv sync --extra eval --group dev                # local environment
.venv/bin/python -m pytest                     # unit tests (local)
.venv/bin/python scripts/sanity.py             # constants: SPEC_PATH, DEVICE
.venv/bin/python scripts/build_codebook.py     # constants: D, K, N_LEVELS, ...
.venv/bin/python scripts/eval_cuda.py          # constants: BITS, TASKS, TAG, ...
.venv/bin/python scripts/key_recall.py         # constants: BITS, DEPTHS, TRIALS, ...
.venv/bin/python scripts/sync_env.py --check   # env.yaml vs pyproject (git hook does this)
```
